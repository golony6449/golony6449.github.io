# 1장 FreeCAD MCP 붙이기와 10mm 정육면체

## 말로 하는 CAD를 준비하다

3D 프린터로 첫 물건을 뽑으려면 먼저 3D 모델이 있어야 한다. CAD 도구로 **FreeCAD 1.1.4**를 골랐고, 여기에 Claude가 직접 모델을 만들고 수정할 수 있도록 **FreeCAD MCP**(`neka-nat/freecad-mcp`)를 연결했다.

이전 세션에서 마친 설치 절차는 간단하다.

1. Claude Code에 MCP 서버를 등록한다.
   ```text
   claude mcp add --scope user freecad -- uvx freecad-mcp
   ```
2. FreeCAD MCP 애드온 폴더를 FreeCAD 애드온 경로(`%APPDATA%\FreeCAD\v1-1\Mod\FreeCADMCP`)에 복사한다.
3. FreeCAD를 실행한 뒤, 애드온의 RPC 서버를 켜 둔다(`localhost:9875`).

주의할 점은 FreeCAD 프로그램 자체가 떠 있고 RPC 서버가 켜져 있어야 한다는 것이다. FreeCAD가 꺼져 있으면 MCP 도구를 호출해도 연결이 실패한다.

## 도구 16개와 RPC 상태 확인

2026년 11월 15일 오전 11시 무렵, 새 세션을 열고 `freecad` MCP 도구가 제대로 올라왔는지 확인했다. 세션에서 도구는 지연 로딩되므로 먼저 검색해서 불러온다. 로드된 도구는 모두 **16개**였다.

- 문서 만들기
- 객체 만들기·수정·삭제
- 파이썬 코드 실행
- 화면 캡처
- FEM 해석 등

먼저 `get_rpc_status`로 FreeCAD 쪽 연결 상태를 확인했다.

| 항목 | 확인 결과 |
|---|---|
| 애드온 버전 | `0.1.31` |
| `gui_dispatch.state` | `healthy` |
| `version_check` | `ok` |

연결은 깨끗하게 붙어 있었다.

## 첫 동작 확인: `CubeTest` 10×10×10mm

본격적인 케이스 설계에 들어가기 전에, AI가 FreeCAD를 정확히 조종하고 그 결과를 스스로 검증할 수 있는지 가장 단순한 물체로 시험해 보기로 했다. 10mm 정육면체다.

과정은 세 단계로 진행했다.

1. **생성**: `CubeTest`라는 새 문서를 만들고 `Part::Box`로 `10 × 10 × 10mm` 정육면체를 만들었다.
2. **화면 확인**: FreeCAD 화면을 **등각 뷰(Isometric)**로 캡처해 눈으로 모양을 확인했다.
3. **수치 재확인**: 파이썬 코드로 객체의 형상 속성을 다시 읽어 검증했다.

파이썬으로 다시 읽은 수치는 이랬다.

- 부피: **`1000mm³`**
- 면의 개수: **`6개`**
- 형상 유효성(`isValid`): **통과**

"말로 하는 CAD"의 첫 장면이었다. AI에게 치수를 말하면 FreeCAD 안에 솔리드가 생기고, AI가 직접 등각 뷰 화면을 캡처해 눈으로 본 뒤, 파이썬으로 부피와 유효성까지 다시 잰다. 이 루프가 돌아가는 것을 확인하고 나서야 비로소 진짜 케이스를 만들어 달라고 요청했다.

> **교훈** — 본격적인 설계에 들어가기 전에 10mm 정육면체 하나로 RPC 연결, 화면 캡처, 수치 검증(`isValid`·부피) 루프가 모두 도는지 먼저 확인해 두면, 이후 모델링에서 생기는 문제를 도구 탓과 설계 탓으로 가르기 쉽다.
