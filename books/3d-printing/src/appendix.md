# 부록. 케이블 고정 방식, 공차 기본값, 용어집

이 부록은 이번 케이스를 설계하며 정리한 케이블 고정 방식, 공차·치수 기준, 그리고 본문에 나온 주요 용어를 한곳에 모은 것이다.

## 1. 케이블 고정 방식(스트레인 릴리프) 7종 비교

3차·4차 설계 과정에서 검토한 케이블 고정 방식과 그 장단점이다.

| 방식 | 장점 | 단점 |
|---|---|---|
| **입구 U홈 + 덮개 반원 홈** | 단순하다 | 당김에 약하다. 위치 잡기용이다 |
| **케이블 타이 앵커** (바닥 돌기 관통 구멍, 4mm 타이면 4.5 × 2mm 정도) | 지름을 몰라도 되고 강하다 | 케이블 타이가 필요하다 |
| **덮개 클램프** (0.5mm 누름) | 추가 부품이 필요 없다 | 케이블 지름에 민감하다 |
| **S자 굴곡** (기둥 사이 지그재그) | 추가 부품이 필요 없다 | 공간이 많이 들고, 뻣뻣한 케이블은 어렵다 |
| **캡스턴** (기둥에 한 바퀴 감기) | 당김을 확실히 받는다 | 케이스 폭·높이가 늘어난다 |
| **케이블 글랜드** (PG7 등) | 가장 튼튼하고 방수도 된다 | 부품을 사야 하고, 커넥터 쪽 끝으로는 통과하지 못한다 |
| **매듭** | 공짜다 | 굵은 케이블에는 맞지 않는다 |

## 2. 공차 및 치수 기본값

### 설계 공차 기본값 (출력 전 가정, 실물로 조정)

단위는 모두 **mm**다.

| 항목 | 기본값 | 비고 |
|---|---|---|
| 벽·바닥 두께 | `2.0` | |
| 부품 둘레 틈 | `0.25` | |
| 덮개 테두리와 벽 사이 | `0.2` | 안쪽 테두리 끼움(깊이 `2~3mm`, 두께 `1.5mm`) |
| 덮개 클램프가 케이블을 누르는 양 | `0.5` | |
| 입구 반원 홈 | `케이블 지름 - 0.2` | 살짝 쥠 |
| 입구 U홈 폭 | `케이블 지름 + 0.5` | |

### 현재 케이스(4차·8mm 반영안) 주요 치수 요약

| 항목 | 값 (mm) | 근거 |
|---|---|---|
| 케이스 외형 (길이 × 폭 × 높이) | `139.5 × 44 × 23` | 확정안 (`can_wrap_case.py`) |
| 캡스턴 기둥 지름 / 굽힘 반경 | `20` / `14` | 케이블 지름 `8mm` 반영 |
| 케이블 지름 | 약 `8` | 사용자 대략 측정 |
| Waveshare USB-CAN-A 전체 길이 | `78.52` | 제조사 외형도 |
| Waveshare USB-CAN-A 본체 | `56.38 × 18.36` | 제조사 외형도 |
| USB-A 플러그 폭 / 노출 길이 | `12.00` / 약 `13.27` | 제조사 외형도 (길이 계산) |
| 나사 단자대(KF2EDG) 길이 | `8.87` | 제조사 외형도 |
| USB-CAN-A 두께 | `10` (가정) / 약 `7.5~8` (사진 추정) | 출력 전 결정 대기 |
| 단자대 폭 | `12` | 가정 |

## 3. 용어집

**FreeCAD MCP**
FreeCAD를 AI 에이전트가 직접 조작할 수 있게 연결해 주는 MCP 서버(`neka-nat/freecad-mcp`). FreeCAD 애드온의 RPC 서버(`localhost:9875`)를 통해 객체 생성, 파이썬 코드 실행, 화면 캡처 등을 수행한다.

**간섭 검사 (`boolean common`)**
조립 상태(닫힌 위치)로 부품들을 옮긴 뒤 서로 겹치는 교집합 부피(`a.common(b).Volume`)를 계산해 충돌 여부를 검증하는 방법.

**STL (Stereolithography)**
3D 모델의 표면을 수많은 삼각형 메시로 쪼개 저장하는 형식. 3D 프린터 슬라이서에 넣는 출력용 파일로 주로 쓴다. FreeCAD에서는 `shape.tessellate(0.05)`처럼 최대 편차(mm)를 주어 변환한다.

**STEP (Standard for the Exchange of Product Data)**
삼각형으로 근사하지 않고 정확한 솔리드·곡면 형상을 그대로 담는 CAD 교환 형식. 다른 CAD 프로그램에서 수정하거나 공유할 때 쓴다.

**U홈과 덮개 혀**
테두리가 있거나 위에서 내려 꽂아야 하는 부품을 벽에 넣기 위해 벽 구멍의 위쪽을 터 놓은 U자 홈과, 덮개를 닫을 때 그 위쪽 빈 공간을 메우며 부품을 위에서 누르도록 덮개에 달아 내린 벽 두께만 한 판("혀").

**스트레인 릴리프 (Strain Relief)**
외부에서 케이블을 잡아당기는 힘(장력)이 내부의 얇은 전선, 납땜, 나사 단자대까지 전달되지 않도록 케이블 피복이나 케이스 구조물이 먼저 힘을 받아 주는 설계.

**캡스턴 (Capstan)**
원통 기둥에 줄이나 케이블을 감아 마찰력을 크게 높이는 원리. 감은 각도 θ에 따라 마찰력이 지수적으로 커진다(캡스턴 공식 `e^(μθ)`). 한 바퀴(360°)만 감아도 당기는 힘 대부분을 기둥이 받는다.

**외팔보 (스프링 손가락)**
한쪽 끝만 덮개에 고정되고 반대쪽 끝이 자유롭게 휘는 얇은 탄성 돌기. 부품 높이에 `1~2mm` 오차가 있거나 유선형 곡면일 때, 손가락이 휘면서 부품을 눌러 공차를 흡수한다.

**정사영 (평행 투영)**
카메라 시선이 평행하다고 보는 투영 근사. 망원 렌즈로 찍은 제품 사진처럼 원근 왜곡이 작을 때 적용하며, 투영 행렬의 두 행이 직교하고 길이가 같다는 성질을 이용해 비스듬한 사진에서 세 번째 축(두께)의 길이를 계산할 수 있다.

**KF2EDG**
Waveshare USB-CAN-A 반대쪽 끝에 달린 3핀(GND, CAN H, CAN L) `3.81mm` 간격 나사 단자대 규격.

**J1962**
자동차 OBD2 16핀 진단 커넥터의 표준 규격(SAE 유료 문서). 이 책에서는 `6번` 핀(CAN H), `14번` 핀(CAN L), `5번` 핀(신호 접지, GND)을 사용한다.
