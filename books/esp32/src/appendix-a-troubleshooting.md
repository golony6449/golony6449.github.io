# 부록 A. 삽질 사례집

"증상 → 처음 의심한 것 → 진짜 원인 → 조치" 순서로 정리한다. 모두 필자가 Waveshare ESP32-S3-Touch-LCD-4.3B, Arduino IDE 2.x, esp32 보드 패키지 3.0.7에서 실제로 겪은 것이다.

## A.1 보드와 백업

| 증상 | 처음 의심한 것 | 진짜 원인 | 조치 |
|---|---|---|---|
| 공장 데모 로그에 `DI & DO Failure!!!` | 보드 불량 | 절연 DIO 자가 검사는 DO0↔DI0, DO1↔DI1을 점퍼로 이어야 통과 | 정상. 검사하려면 점퍼를 잇는다(1장) |
| 플래시 백업이 진행 표시 없이 멈춤 | 도구 고장 | 출력을 `tail`로 받아 진행이 안 보였고, 보드가 다운로드 모드를 벗어남 | 로그를 파일로 남기고 기본 속도로 재실행(1장) |
| 백업 중 재부팅 | 전원 부족 | esptool의 리셋이거나 브라운아웃. **확인 필요** | 다시 생기면 `rst:` 코드 확인 |
| CH343 칩을 거치지 않는다 | 연결 이상 | 이 보드에는 CH343이 없다. USB-C가 칩 내장 USB(GPIO19/20)에 바로 연결 | 정상(2장 회로도) |

## A.2 Arduino 환경

| 증상 | 처음 의심한 것 | 진짜 원인 | 조치 |
|---|---|---|---|
| 컴파일이 `exit status 1` 한 줄로 실패 | 코드, 설치 | IDE가 USB ID를 보고 `ESP32 Family Device`를 자동 선택 | Board = `ESP32S3 Dev Module`(3장) |
| 업로드가 `ClearCommError ... PermissionError(13)` | 드라이버 | 다운로드 모드로 리셋하며 USB가 재열거되는 사이 포트를 잃음(**추정**). 자동 리셋 회로 없음 | BOOT 누른 채 RESET → BOOT 떼기. 첫 한 번만 필요했다 |
| 업로드 후 화면이 검게 남음 | 화면 고장 | 공장 데모를 덮어써서 화면을 켜는 코드가 없음 | 정상 |
| 시리얼에 `ESP-ROM:esp32s3-20210327` 한 줄 뒤 침묵 | 프로그램 멈춤 | 보드를 바꾸며 `USB CDC On Boot`가 `Disabled`로 초기화 → `Serial`이 UART0(RS485 단자)으로 나감 | `USB CDC On Boot` = `Enabled`. 빌드 크기 302KB(켜짐)/278KB(꺼짐)로 판별(3장) |

## A.3 LVGL 데모

라이브러리는 위키에 적힌 셋 말고 `esp-lib-utils`도 필요하다. 데모 zip의 라이브러리 폴더 넷을 모두 복사했다(4장).

| 증상 | 처음 의심한 것 | 진짜 원인 | 조치 |
|---|---|---|---|
| 첫 빌드가 10분 넘게 걸림 | 멈춤 | LVGL 파일이 많음 | 기다린다. 두 번째부터 캐시로 빠름 |
| 업로드가 `Could not open COM9, the port doesn't exist`. 장치 관리자에는 있음 | 포트 이름 | IDE Serial Monitor가 포트를 잡고 있음. esptool v5는 `PermissionError(13)`로 보여 줌 | Serial Monitor를 닫는다(4장) |
| 데모 화면이 잘리고 터치가 안 됨 | 초기불량 | 데모 설정 파일이 5인치 보드와 공용. 기본 1024×600, 터치 꺼짐 | 800×480, 터치 켬, VBP/VFP 8(라이브러리의 4.3B 정의와 맞춤)(4장) |

## A.4 FreeRTOS 실험

| 증상 | 처음 의심한 것 | 진짜 원인 | 조치 |
|---|---|---|---|
| 스케치 주석의 예시 hwm과 실측이 다름 | — | AI 주니어가 짐작으로 쓴 값 | 실측값으로 수정(5장) |
| `Stack canary watchpoint triggered (my_task)` 반복 | — | 스택 1024바이트에서 첫 `printf`(약 1,660바이트 필요)가 넘침 | 의도한 크래시. 스택을 4096으로 되돌림(7장) |
| 크래시 펌웨어를 고친 버전으로 올릴 수 없음(`port doesn't exist`, `Write timeout`) | 케이블 | 재부팅 루프로 내장 USB가 1초마다 사라짐 | BOOT+RESET으로 다운로드 모드에서 올린 뒤 RESET(7장) |
| 시리얼에 첫 몇 줄이 안 보임 | 출력 누락 | 리셋 뒤 USB가 다시 연결되는 사이 출력이 지나감 | 첫 순간의 값을 변수에 적어 두고 매 줄에 붙여 찍는다(`first=`). 이 방법으로 첫 실행 코어가 core 1임을 확인(7장) |
