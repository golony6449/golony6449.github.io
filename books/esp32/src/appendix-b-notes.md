# 부록 B. 질문 노트와 감탄 노트

본문에 흩어진 노트를 한곳에 모았다. 따옴표 안은 실제로 입력한 그대로다.

## 질문 노트

| 장 | 질문 | 짧은 답 |
|---|---|---|
| 1 | "그 전에 초기불량 테스트는?" | 굽기 전에 공장 상태를 기록해야 나중에 보드 불량과 내 코드 문제를 가를 수 있다 |
| 1 | "어라 왜 재부팅되지?" | esptool의 리셋일 수도, 전원 부족일 수도 있다. 리셋 코드로 확인한다 |
| 2 | "ch343을 거쳐야 좋은거 아냐?" | 이 보드에는 CH343이 없다. 칩 내장 USB는 JTAG 디버깅까지 준다 |
| 3 | "expressif가 esp32 제조사야?" | 맞다. 철자는 Espressif. Arduino 코어도 그들이 관리한다 |
| 3 | "esp32 침인데 개발툴은 어떻게 아두이노꺼로 쓸수있어?" | Arduino는 API 규격과 IDE이고, Espressif가 만든 ESP32 코어가 ESP-IDF 위에서 그 API를 구현한다 |
| 3 | "4.0이 최신인데 이걸로 설치하면 안돼?" / "3.3.13은?" | 먼저 제조사가 검증한 3.0.7로 기준점을 잡고 한 계단씩 올린다 |
| 3 | "리셋 했는데 검은화면 그대로야. 아 이건 펌웨어를 덮어 써서 그런가?" | 맞다. 화면을 켜는 코드가 없다 |
| 3 | "이거 뒤로 글자가 없는디?" | `Serial`이 UART0(RS485 단자)으로 나가고 있다. `USB CDC On Boot`를 켠다 |
| 3 | "매번 해야해?" | 아니다. 보드를 바꿀 때만 초기화된다 |
| 4 | "너도 빌드하고 업로드할수 있지?" | `arduino-cli`로 IDE와 같은 설정을 써서 할 수 있다 |
| 4 | "터치안되고, 화면도 이상해. 짤려 나오는데?" | 데모 설정이 5인치 보드용 기본값이었다 |
| 5 | "가능하면 주니어에게 위임도 시켜볼래?" | 짤 코드가 없는 작업이라 맡기지 않았다. 코드가 생기는 다음 과제부터 맡겼다 |
| 5 | "이 워크트리 내에서 하면 되지?" | 되지만 라이브러리 2,300개 파일을 커밋하게 된다. 대신 빌드 스크립트를 저장소에 뒀다 |
| 6 | "이걸로 어떤 결론을 알수있어?" | `loop()`도 태스크다 / affinity 없음은 무작위가 아니다 / 스택은 재서 정한다 |
