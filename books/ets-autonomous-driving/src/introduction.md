# 서문: 이 노트를 읽는 법

## 무엇을 만들었나

유로트럭 시뮬레이터 2(ETS2) 화면을 캡처해 차선·미니맵·차량을 인식하고, 규칙 기반 판단으로 목표 속도와 조향을 정한 뒤, 가상 게임패드로 트럭을 움직이는 자율주행 연구 플랫폼이다. 한 제어 주기는 다음 단계를 거친다.

```text
캡처 → 텔레메트리 → 인식 → 판단 → 제어 → 구동 → HUD·녹화
```

판단을 홈서버로 옮기는 분산 실행, 대시보드, 운전자 개입 시 즉시 손을 떼는 안전 장치도 함께 만들었다.

## 누가 만들었나

코드는 대부분 사람이 직접 치지 않았다. 사람은 방향을 정하고 실차(게임)에서 시험했으며, 여러 AI 에이전트가 역할을 나눠 일했다.

| 역할 | 맡은 일 |
|---|---|
| 사람 | 목표·결정, 실게임 시험, 승인 |
| 설계 에이전트 | 원인 분석, 설계, 일감 쪼개기, 구현 계획 |
| 실행 에이전트 | 작업 공간 준비, 위임, 검토 결과 처리, 머지 |
| 구현 에이전트(DeepSeek) | 계획대로 코드와 테스트 작성 |
| 검토 에이전트(Qwen) | 변경 검토와 수정 지시 |

어느 에이전트가 무엇을 맡았는지, 비용이 얼마였는지, 어떤 판단을 했는지는 본문에 그때그때 적혀 있다.

## 이 노트의 성격

이 책은 다시 쓴 원고가 아니라 **작업하면서 쓴 집필 노트 원문**이다. 날짜순으로 읽으면 된다.

- 사람이 한 질문과 결정은 그 말 그대로 따옴표로 남겼다. 오타도 고치지 않았다.
- 시각은 한국 시간(KST)이다.
- 각 절 끝의 "교훈"과 "책 소재"는 나중에 책으로 다시 쓸 때 쓸 재료다.
- 본문에 나오는 `docs/...`, `src/...` 같은 경로는 비공개 원본 레포 기준이라 링크로 열리지 않는다.
