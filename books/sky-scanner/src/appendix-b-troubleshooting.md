# 부록 B. 삽질 사례집

"증상 → 처음 의심한 것 → 진짜 원인 → 조치" 순서로 정리한다. 모두 필자가 실제로 겪은 것이다. 같은 증상이라도 장비와 버전에 따라 원인이 다를 수 있다.

## B.1 수신

| 증상 | 처음 의심한 것 | 진짜 원인 | 조치 |
|---|---|---|---|
| SDR++에서 FM이 "치익" 소리만 남. 게인을 올리면 워터폴에 줄이 보이고 소리 결만 조금 바뀜 | 주파수, 모드, 게인 설정 | 동글이 V4L(제품 이름 `Blog V4L`)인데, SDR++에 들어 있던 `rtlsdr.dll`은 정확히 `Blog V4`만 V4로 알아봄 | rtl-sdr-blog V1.4.0 `rtlsdr.dll`로 교체(1장) |
| 새 드라이버를 받아 뒀는데도 그대로 | 드라이버 설치 실패 | SDR++는 자기 폴더의 DLL을 먼저 읽음. 받아 둔 폴더는 쓰지 않음 | SDR++ 폴더의 `rtlsdr.dll` 자체를 교체 |
| DLL을 바꾸려는데 실패 | 권한 | SDR++가 실행 중이라 파일이 잠김 | SDR++를 끄고 교체 |
| 에어밴드 교신 사이에 잡음이 계속 깔림 | 수신 불량 | 스켈치를 안 씀 | Squelch Mode `Power`, 잡음이 끊기는 지점보다 조금 위(4장) |
| 스켈치를 맞춰도 금방 다시 안 맞음 | — | 게인, 시간대, 날씨에 따라 잡음 바닥이 움직임 | 앱에서는 잡음 바닥을 따라가는 자동 스켈치로 설계 |

## B.2 ADS-B

| 증상 | 처음 의심한 것 | 진짜 원인 | 조치 |
|---|---|---|---|
| `rtl_adsb`가 30초에 46개 메시지를 냈는데 비행기가 0대 | 안테나 | 메시지 전부가 CRC를 통과하지 못한 잡음 해독. `rtl_adsb`는 약한 테스트용 해독기 | CRC로 검증하고 dump1090으로 교체 → 비행기 3대(5장) |
| 동글이 다른 프로그램에서 "No supported devices found" | 드라이버 | 동글이 PC에서 빠져 있었음(장치 목록에 없음) | 장치 관리자나 장치 목록에서 VID 0BDA를 먼저 확인 |
| dump1090을 처음 실행하면 설정 마법사가 뜸 | — | 설정 파일의 집 위치가 `-1,-1`이면 첫 실행에 마법사를 띄움 | `dump1090.cfg`의 `homepos`를 미리 채우고 `location = no` |

## B.3 구현(1차)

| 증상 | 원인 | 조치 |
|---|---|---|
| (잠재) 기본 설정에서 동글이 항상 "열 수 없음" | ppm 0을 다시 설정하면 librtlsdr가 -2를 돌려주고 pyrtlsdr가 예외를 냄 | ppm이 0이 아닐 때만 설정(7장) |
| (잠재) 매 블록 `Short read`로 동글이 닫히고 재연결 | 한 번에 480,000바이트를 읽음. USB 단위 512바이트의 배수가 아님 | 16,384샘플(32KB) 단위로 읽고 남는 것은 버퍼에(7장) |
| 재생 모드에서 교신 길이가 실제보다 길게 기록됨 | FileSource가 블록마다 쉬는 시간에 처리 시간이 더해져 실시간보다 느림 | 재생 모드 한정. 처리 시간을 빼고 쉬도록 고칠 예정 |
| `gh pr merge --delete-branch`가 "Permission denied"로 워크트리를 못 지움 | 진행 탭이 그 폴더를 열고 있음 | 머지 전에 진행 탭부터 닫기 |
| `gh pr ready`가 "Something went wrong"을 반복 | GitHub GraphQL 일시 장애. REST로는 Draft 해제 불가 | 1분 간격 재시도 |
| 통합 PR 리뷰가 `too_large`로 거절 | 차수 전체 diff가 리뷰 도구 한도를 넘음 | 작업 PR별 리뷰 + 실서버 끝에서 끝까지 확인으로 대신 |

## B.3.1 실기와 로컬 모델(12~13장)

| 증상 | 원인 | 조치 |
|---|---|---|
| `AttributeError: function 'rtlsdr_set_dithering' not found` | pyrtlsdr 0.4.0+는 rtl-sdr-blog DLL에 없는 함수를 시작할 때 찾음 | pyrtlsdr 0.3.0 + `setuptools<81` 고정(12장) |
| 녹음이 배속처럼 들림(재생 길이 / 실제 시간 = 0.61~0.66) | 읽기와 신호 처리를 번갈아 해서 처리 중 샘플이 버려짐 | 읽기 전용 스레드 + 대기열(12장) |
| Qwen이 영어 교신을 중국어나 엉뚱한 문장으로 적음 | 언어·맥락을 안 줌 | 언어 en + 항공 무전 맥락(12장) |
| 버튼을 추가했는데 화면에 안 보임 | 브라우저가 옛 JS를 캐시에서 씀 | 화면 파일에 `Cache-Control: no-cache` |
| GPU 모델이 한 건에 10~22초, 또는 멈춤 | `cublas64_12.dll`을 못 찾아 조용히 CPU로 내려감. CTranslate2는 cuBLAS를 늦게 불러 PATH만 봄 | DLL 폴더를 PATH에도 추가, CPU 전환 시 경고(13장) |
| large-v3 변환 중 Segmentation fault | Windows에서 `--low_cpu_mem_usage` 경로 | 파이썬 API로 `load_as_float16=True`(13장) |
| 변환 중 `vocab_file`이 None | 오프라인 모드라 단어표를 못 받음 | 오프라인 모드 끄고 재실행 |
| 엔진을 바꾸자 대기열이 가득 참 | 시작 따라잡기가 지난 교신 1,389개를 다 넣음 | 따라잡기 끄기 옵션 + 최대 500개(13장) |
| 서재에서 녹음 0건, 잡음 +10 dB | 실내 전자기기 잡음 + 금속 방범창 차폐 | 베란다로 되돌림(12장) |

## B.3.2 리눅스 서버(15장)

| 증상 | 원인 | 조치 |
|---|---|---|
| 빌드가 `LibUSB 1.0 required`, 그런데 마지막에 DONE이 찍힘 | 여러 줄 명령의 `\` 뒤 공백으로 명령이 끊김 | 한 줄짜리 명령으로 다시 |
| `tailscale serve`가 아무 말 없이 멈춤 | tailnet에서 Serve가 꺼져 있다는 안내를 파이프가 숨김 | 출력을 파일로 받아 확인, 관리자 화면에서 켜기 |
| `serve config denied` | root 권한 필요 | `tailscale set --operator=$USER` 한 번 |
| hosts의 짧은 이름으로 HTTPS 거부 | 인증서와 serve 규칙이 ts.net 이름 기준 | ts.net 이름으로 접속 |
| 502 | 서버 전체가 꺼졌다 켜져 앱이 없음 | 앱 재시작, 로그를 임시 폴더 밖으로 |
| 서버가 부하 7분 뒤, 또는 부팅 2초 만에 꺼짐(정상 종료 흔적 0) | 67W 노트북 어댑터 용량 초과 | 100W 어댑터로 교체 |

## B.3.3 고아 프로세스와 도메인/SSL (17장)

| 증상 | 원인 | 조치 |
|---|---|---|
| 프로세스가 살아있는데 CPU 117% 과점유, 500 에러 및 파일 경로 무한 에러 | 에이전트 워크스페이스가 삭제된 후 프로세스만 고아 데몬으로 남아 작업 디렉터리가 `... (deleted)` 상태가 됨 | 프로세스 종료 후 메인 레포에서 재실행. "하드웨어·포트 점유 데몬은 메인 레포에서만 실행" 원칙 확립(17장) |
| 여러 웹앱을 Nginx `/static`으로 묶었더니 다른 서비스의 화면이 깨짐 | 여러 프로젝트가 `style.css`, `app.js` 등 동일한 정적 파일명을 공유해 이름 충돌 | 단일 `/static` 순차 탐색 대신, 개인 도메인 사설 서브도메인(`sky-scanner.golony.dev`)으로 완전 분리(17장) |
| `*.golony.dev` 와일드카드 인증서를 적용했는데 루트 도메인(`golony.dev`)에서 인증서 오류 | Let's Encrypt 와일드카드(`*.도메인`)는 루트 도메인 본체를 포함하지 않음 | `-d golony.dev -d "*.golony.dev"`를 하나의 통합 SAN 인증서로 확장(`--expand`) 발급(17장) |

## B.5 작업 환경

| 증상 | 원인 | 조치 |
