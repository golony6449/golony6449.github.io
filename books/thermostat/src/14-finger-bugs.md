# 14장 손가락이 찾아낸 버그 넷

## 14.1 화면이 켜졌다

Waveshare 4.3B의 800×480 화면에 LVGL 8.4로 만든 터치 UI(`demos/03_ui`, SCRUM-237)를 올렸다. 첫 고비는 한글이었다. LVGL 기본 폰트에는 한글이 없다. 파이썬 스크립트(`tools/gen_kr_font.py`)로 화면에 실제로 쓰는 한글 글리프만 뽑아 C 폰트 파일(`kr_font_20.c`, `kr_font_28.c`)을 만들었다. 한글 전체를 넣으면 플래시를 크게 차지한다.

보드에 올리기 직전 코드 검토에서 버그 하나를 먼저 잡았다. 터치 콜백 4개가 화면 상태(`g_view_model`)를 갱신하지 않아서, 1초마다 도는 `refresh_ui()`가 필자가 방금 누른 값을 원래대로 되돌릴 수 있었다. 4줄을 고쳐서 올렸다.

보드에서 잰 메모리(**실측**):

| 상황 | 남은 내부 RAM | 남은 PSRAM |
|---|---|---|
| Wi-Fi 켜짐 + 800×480 LVGL | 약 170KB | 약 5.8MB |

화면 버퍼가 8MB PSRAM에 올라가서 여유가 넉넉했다.

## 14.2 직접 눌러 본 뒤에 나온 것

보드를 손가락으로 눌러 본 필자가 네 가지를 한꺼번에 보냈다.

> "터치 잘 되고, UI 개선건 알려줄게
>
> 1. 이거 다크모드야? 목표온도 +/- 버튼이 잘 안보여.
> 2. 이게 그대로 기본적으로는 온도조절기인데, 좌측에 온도 조절 부분 크기가 너무 작아. 화면을 좌우 말고 상하로 나눠서 재배치 해주고, 조작버튼은 가능한 크게 해보자.
> 3. 반복 일때는 시간이 나와야 될것 같은데, 여전히 온도가 나와.
> 4. 꺼짐일때는 온도 설정이 안되어야 할것 같은데 조절이 되네? -으로 나오게 해줘
>
> 각각 티켓으로 등록해주고, 이어서 agy 모드의 지라 워크플로우로 작업해보자."

네 가지 모두 **코드를 눈으로 읽어서는 찾기 어렵고, 실물 화면을 손으로 눌러 봐야 드러나는 문제**였다.

| 일감 | 증상(**실측**) | 원인과 개선 |
|---|---|---|
| SCRUM-248 | 어두운 배경에서 `+/-` 버튼 글자가 안 보인다 | `create_button()`에서 라벨 글자색을 안 줬다. LVGL 기본 검정 글자가 어두운 버튼 위에 그려졌다. 밝은 글자(`0xF8FAFC`)와 2px 테두리(`0x64748B`)를 넣었다 |
| SCRUM-249 | 좌우 분할이라 조작 버튼이 작다 | **상하 분할**로 바꿨다. 위: 현재 온도, 난방 표시, 센서 출처, 시각. 아래: 큰 `+/-` 버튼, 48px 한글 폰트(`kr_font_48.c`), 모드 버튼 3개 |
| SCRUM-250 | 반복 모드에서도 가운데에 목표온도가 나온다 | 모드에 따라 가운데 값이 `목표 온도 (22.5℃)` ↔ `반복 시간 (15분)`으로 바뀐다. 반복 시간은 큰 `+/-`로 5분씩 조절 |
| SCRUM-251 | 꺼짐 모드에서도 `+/-`가 눌린다 | 꺼짐이면 가운데 값을 `-`로 표시한다. 버튼을 LVGL 비활성 상태로 만들고, 핸들러에서도 `can_adjust_primary()`로 한 번 더 막는다 |

> **질문 노트** — "이거 다크모드야? 목표온도 +/- 버튼이 잘 안보여." → LVGL 버튼 라벨에 글자색을 안 줘서, 기본 검정 글자가 어두운 배경에 묻혔다.

> **웹 개발자 시선** — CSS에서 다크 테마 버튼에 배경만 지정하고 `color`는 상속에 맡겼더니, 기본 검정 글자가 묻혀 버린 것과 같다. LVGL도 스타일 속성을 안 주면 기본 테마 색이 들어온다.

SCRUM-251의 이중 잠금은 웹에서도 익숙한 방식이다. 버튼을 `disabled`로 바꾸는 것(화면)과, 서버에서 한 번 더 검사하는 것(핸들러)을 둘 다 한다. 한쪽만 하면 언젠가 다른 경로로 뚫린다.

## 14.3 "잘 되네."

네 가지를 PR 하나(#8)로 합쳐 머지하고 다시 보드에 올렸다. 플래시는 41%, RAM은 29%를 썼다.

> "잘 되네."

> **감탄 노트** — 실물 화면에서 찾은 네 건을 한 번에 고쳐 다시 올렸을 때 들은 한마디다.

## 알게 된 점

- 호스트 단위 테스트를 아무리 짜도 "글자가 안 보인다"는 잡히지 않는다. 화면 작업은 실물을 눌러 보는 단계가 완료 기준에 들어가야 한다.
- 온도조절기 화면의 주인공은 조작 버튼이다. 정보를 늘어놓기 전에 "손가락이 어디를 누르나"부터 정한다.
- 누를 수 없어야 하는 버튼은 화면과 핸들러 두 곳에서 막는다.
- 한글 폰트는 쓰는 글자만 뽑는다. 플래시는 넉넉해 보여도 금방 찬다.
