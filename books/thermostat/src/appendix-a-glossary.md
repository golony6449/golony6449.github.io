# 부록 A. 용어집

웹 개발자 시선의 비유는 정확한 정의가 아니라 감을 잡기 위한 손잡이다.

## A.1 집과 난방

| 용어 | 뜻 | 웹 개발자 시선 | 본문 |
|---|---|---|---|
| 지역난방 | 집에 보일러가 없고, 단지 밖에서 데운 온수를 받아 쓰는 방식 | 자체 서버 대신 외부 공급 서비스 | 서문, 2장 |
| 분배기 | 집 안 바닥 배관 루프들이 모이는 곳. 보통 싱크대 밑이나 다용도실 | 로드 밸런서처럼 한 곳에서 갈라지는 지점 | 2장 |
| 구동기 | 분배기 밸브 위에서 220V로 밸브를 여닫는 부품 | 실제로 일을 하는 워커 | 3장 |
| 왁스(열동)식 구동기 | 전기로 왁스를 데워 팽창시켜 밸브를 여는 방식. 몇 분 걸리고 켜짐/꺼짐뿐 | 시작이 느린 콜드 스타트 | 3장 |
| NO / NC | 전원이 없을 때 열려 있는가(NO) 닫혀 있는가(NC). NO면 제어가 뒤집힌다 | 기본값이 allow인가 deny인가 | 9장 |
| 조절기(벽 조절기) | 온도를 보고 회로를 끊었다 잇는 장치. 이 프로젝트가 대체하려는 것 | 이 프로젝트의 클라이언트 | 2장, 11장 |
| 월패드 | 현관 쪽 홈네트워크 화면. 최근 아파트는 조절기와 RS-485로 묶인다 | 사내 관리 콘솔 | 2장 |

## A.2 전기

| 용어 | 뜻 | 웹 개발자 시선 | 본문 |
|---|---|---|---|
| L선 / N선 | 220V 회로의 활선(L)과 중성선(N) | 요청선과 귀환선 | 2장 |
| 2선식 루프 | 벽 조절기에 L선만 들어왔다 나가는 구조. 벽 박스에 N이 없다 | 미들웨어가 요청을 통과시키거나 끊기만 하는 구조 | 2장 |
| 무중성선 스위치 | N선 없이 동작하는 스마트 스위치. 꺼져 있을 때도 미세 전류로 자기 전원을 얻는다 | 연결이 끊긴 척하면서 하트비트는 흘리는 클라이언트 | 2장 |
| 최소 부하 | 무중성선 제품이 안정적으로 동작하는 데 필요한 부하의 최솟값 | 최소 트래픽이 있어야 켜져 있는 서비스 | 2장, 3장 |
| 레버식 커넥터(흔히 와고) | 레버로 선을 고정하는 전선 커넥터. 다시 풀 수 있다 | 언제든 롤백 가능한 설정 | 4장 |
| 검전기 | 선에 전기가 있는지 확인하는 도구. 차단기를 내린 뒤 반드시 쓴다 | 배포 전 헬스체크 | 3장, 11장 |
| 고스트 전압 | 꺼진 선에서 테스터에 잡히는 애매한 전압. 유도나 누설 전류 때문 | 지워진 캐시에서 읽힌 오래된 값 | 11장 |
| LoZ 모드 | 테스터의 저임피던스 측정 모드. 고스트 전압을 걸러 낸다 | 캐시를 우회한 직접 조회 | 11장 |

## A.3 스마트홈

| 용어 | 뜻 | 웹 개발자 시선 | 본문 |
|---|---|---|---|
| Matter | 스마트홈 기기끼리 대화하는 공통 규격. IP 기반 | HTTP 같은 응용 계층 규약 | 5장 |
| Matter over Wi-Fi / Thread | Matter를 싣는 전송 방식. Thread는 802.15.4 전용 칩 필요 | 같은 HTTP를 유선이나 LTE로 싣는 것 | 5장 |
| Zigbee | 무선 규격까지 묶인 스마트홈 통신. 전용 칩과 Zigbee 허브 필요 | 풀스택 독점 프로토콜 | 5장 |
| 허브 | Matter·Zigbee 기기를 받아 루틴을 돌리는 장치 | API 게이트웨이 겸 워크플로 엔진 | 5장 |
| 클러스터 / 엔드포인트 | Matter에서 기능 묶음(예: Thermostat)과 그 기능이 붙는 자리 | 리소스 스키마와 그 리소스의 경로 | 6장 |
| ThermostatRunningState | 온도조절기가 지금 실제로 난방 중인지 알리는 읽기 전용 항목 | 상태 조회 API의 status 필드 | 6장 |
| 루틴 | SmartThings에서 "이런 상태가 되면 저걸 해라" 규칙 | 노코드 자동화(웹훅 + 액션) | 3장, 6장 |
| WWST | Works with SmartThings. 삼성 공식 호환 인증 | 공식 인증 SDK 배지 | 4장 |
| Edge 드라이버 | SmartThings 허브에서 도는 기기 드라이버(Lua). 앱 화면을 커스텀 | 플랫폼용 어댑터 플러그인 | 7장 |
| PAT | SmartThings 개인 액세스 토큰. 최근 것은 24시간 만료 | 짧은 수명의 API 토큰 | 8장 |

## A.4 제어와 펌웨어

| 용어 | 뜻 | 웹 개발자 시선 | 본문 |
|---|---|---|---|
| 히스테리시스 | 켜는 경계와 끄는 경계를 다르게 둬서 경계 근처의 깜빡임을 막는 것 | 디바운스 | 2장 |
| 최소 켜짐/꺼짐 시간 | 한 번 바꾸면 일정 시간 다시 바꾸지 않는 규칙 | 레이트 리밋 | 2장 |
| 시간 비례 제어 | 주기 중 켜는 비율로 평균 출력을 조절 | PWM, 듀티 사이클 스로틀링 | 3장 |
| 온도 모드 | 목표온도에 맞춰 자동으로 켜고 끄는 운전 | 목표값을 따라가는 오토스케일링 | 7장 |
| 반복 모드(예약) | 온도와 상관없이 60분 중 N분 켜는 한국 조절기의 운전. Matter 표준에 없음 | 크론 잡 | 7장 |
| 주간 스케줄 | Matter의 시간대별 목표온도 변경 기능. 반복 모드와 다르다 | 시간대별 설정 프로필 | 7장 |
| 최저온도 보호 | 어떤 모드든 너무 추워지면 강제로 켜는 안전장치 | 하한 알람과 자동 스케일업 | 7장, 9장 |
| 데드맨 스위치(워치독) | 살아 있다는 신호가 끊기면 안전한 상태로 돌아가는 장치. 타이머 + 유지 신호 | TTL 리스, liveness probe | 9장 |
| 유지 신호 | 데드맨 타이머를 다시 시작하게 하는 주기적 신호 | 하트비트, `EXPIRE` 연장 | 9장 |
| NVS | ESP32 플래시에 키-값으로 설정을 저장하는 영역 | 로컬스토리지 | 6장 |
| NTP / RTC | 네트워크로 시간을 맞추는 규약 / 전원이 꺼져도 시간을 세는 칩 | 시간 서버와 로컬 시계 | 8장 |
| LVGL | 마이크로컨트롤러용 GUI 라이브러리 | 임베디드용 UI 프레임워크 | 5장, 10장 |
